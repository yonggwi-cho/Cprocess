# P3: 長期項目の概要仕様

P3 項目は前提タスク (P1/P2) の実装結果に設計が依存するため、
本書では「目的 / 前提 / 設計方針 / 受入基準」の縮約形式で確定し、
**着手時に個別仕様書 (フル 6 節形式) へ展開する**。設計方針に書かれた
選択は確定事項であり、展開時に覆す場合は本書を先に改訂すること。

---

## P3-a: 真の化合物 BCA

**目的**: SiO₂/Si₃N₄ を Bragg 則の単一有効元素で近似している現行 MC を、
成分元素ごとの二体衝突に置き換え、多層構造での後方散乱・混合精度を上げる。

**前提**: なし (mc_implant.cpp のみ)。

**設計方針**: `TargetMaterial` を成分リスト
`{ {Z_i, M_i, 数密度比 x_i} }` に拡張。各衝突で衝突相手を x_i 比例の
確率で抽選し、その元素の (ε, b) 散乱テーブルを引く。散乱テーブルは
(dopant Z1, target Z2) ペアごとに遅延構築しキャッシュ
(`std::map<std::pair<int,int>, ScatterTable>`、スレッド安全に
構築は事前一括)。電子的阻止能は Bragg 則を維持 (成分加重和)。
自由行程は総数密度から。既存の単一元素材料は成分 1 個として
完全後方互換。

**受入基準**:
- 単一元素材料 (Si) の結果が現行実装とビット一致 (成分 1 個の退化)
- SiO₂ 中の B 30keV の Rp が単一有効元素近似と 5–20% ずれる
  (物理的改善の存在確認; SRIM 参照値 ~100nm に近づく方向)
- O 反跳による軽元素後方散乱率が Si 単体より増える (定性)
- 実行時間の増加 < 30%

## P3-b: エピタキシー成長

**目的**: `proc::epitaxy(thickness, temp, time, doping_map)` — その場
ドープを含む Si/SiGe 層の成長。

**前提**: P1-7 (layer_stack)、M-2。

**設計方針**: 幾何は deposit の機構 (extend_mesh_exact + 再タグ) を流用し
材料は silicon (または P3-f の SiGe)。成長中の不純物取り込みは
一様濃度 (doping_map: 種→cm⁻³) で新規セルに設定。成長温度での
熱履歴として、成長時間分の diffuse を自動で 1 回実行 (オプション
`anneal=true` 既定)。成長速度モデル (H₂/SiH₄ 律速) は導入せず
thickness/time 指定とする。

**受入基準**:
- エピ層の厚さ・ドーピングが指定値に一致 (< 1 セル高、< 1%)
- 界面での基板ドーパントのエピ層への遡り拡散が熱履歴と整合
  (2√(Dt) の 30% 以内)
- 多層エピ (3 回連続) で layer_stack が正しく積まれる

## P3-c: 固相エピ再成長 (SPER)

**目的**: MC のアモルファス化領域 (damage ≥ 6.25e21 cm⁻³) が低温アニールで
c-Si に再成長する過程と、そのフロントでのドーパント再分布。

**前提**: P1-2 (損傷場の永続化)、P2-1。

**設計方針**: アモルファス深さ z_a(x,y) を damage 場の閾値交差から抽出し、
フロント速度 v = v0·exp(−3.1eV/kT) (v0=3.1e8 cm/s, <100>) で
z_a を時間発展 (カラム毎 1D)。再成長した領域の damage を 0 化し、
活性化を C_ss(T) でなく **SPER 活性化** (準安定・C_ss の up to 10 倍、
ParamDB キー) とする。スノープラウ (フロントでの不純物押し出し) は
第一段階では省略。diffuse_ted の前処理ステップとして
`proc::sper(temp, time)` を独立コマンド化。

**受入基準**:
- 550–650°C で v が文献 Arrhenius (3.1 eV) に一致 (活性化エネルギー
  フィット誤差 < 5%)
- 600°C で 100nm アモルファス層の全再成長時間が ~分オーダー
- 再成長領域の As 活性濃度が C_ss(600C) を超える (準安定活性化)

## P3-d: シリサイド化

**目的**: Ni/Ti 堆積 + 熱処理での NiSi/TiSi₂ 形成 (Si 消費・体積変化)。

**前提**: P1-6 (酸化の消費/成長機構を流用)、P1-7。

**設計方針**: Deal-Grove 類似の拡散律速成長 x² = B·t (B は金属種と相の
Arrhenius、NiSi: 1.5eV オーダー)。金属材料 (nickel/titanium) と
シリサイド材料を材料表に追加。Si 消費比 (NiSi: 消費 Si 1.83 per 金属 1)
の体積 bookkeeping は oxidize と同じ再タグ方式。ドーパントの
シリサイドへの偏析 (dose loss) は P1-4 の偏析機構に係数追加。

**受入基準**:
- 成長則 x ∝ √t (両対数勾配 0.5 ± 0.05)
- Si 消費厚 / シリサイド厚の比が相の文献値 ± 5%
- シリサイド化後の Si 中ドーズ損失が偏析係数と整合

## P3-e: 応力依存物理

**目的**: P2-6 の応力場を拡散・酸化・活性化へフィードバック。

**前提**: P2-6、P2-4。

**設計方針**: (1) 拡散: D → D·exp(−p·V_act/kT)、p = −tr(σ)/3
(静水圧)、活性化体積 V_act は種別 ParamDB (B: ~0.17 Ω_Si 等)。
dcell 計算ループでセル応力を参照するだけの局所結合 (陽的、
Picard 内で自然に収束)。(2) 酸化: P2-4 の界面反応速度
k_s → k_s·exp(−σ_nn·V_r/kT) (法線応力で減速; bird's beak 先端の
自己制限を再現)。(3) 活性化: C_ss の応力補正は第一段階では省略。

**受入基準**:
- 一様静水圧 1 GPa で B の D が exp(−pV/kT) 倍 (解析値と < 2%)
- 応力ゼロ場では全結果が現行と一致 (< 1e-12)
- LOCOS 形状で応力減速により bird's beak 長が 5–30% 短縮 (定性)

## P3-f: SiGe / 歪みエンジニアリング

**目的**: Ge 組成場 (P2-8 の Ge) から格子失配固有ひずみを生成し
P2-6 で歪み場を解く。ni・拡散への歪み補正。

**前提**: P2-6、P2-8、P3-e。

**設計方針**: 固有ひずみ ε0 = 0.042·x_Ge (Ge 組成比、Vegard 則)。
組成は Ge 濃度 / 5e22 で無次元化。バンドギャップ縮小
ΔEg = 0.4·x_Ge eV → ni 補正 ni_SiGe = ni·exp(ΔEg/2kT)。
拡散補正は P3-e の機構に歪みテンソル依存項を追加 (第一段階は
静水圧成分のみ)。

**受入基準**:
- Ge 20% 層のミスフィットひずみが 0.84% (± 2%)
- ni が SiGe 層で増加し、電界増速拡散が変化する (定性、符号確認)
- Ge=0 で全結果が現行と一致

## P3-g: 1D/2D 高速モード

**目的**: 較正・スイープ用途の 100 倍速実行 (nx=ny=1 の 1D、ny=1 の 2D)。

**前提**: なし (独立)。

**設計方針**: `make_box_mesh` の最小分割制約を確認し nx=1 を許可
(Kuhn 分割は 1 セル幅で成立するか検証 — しない場合は 1D 専用の
プリズム分割を追加)。MC の横方向境界を周期境界 (wrap) に
(現状 out_of_domain になる横方向脱出を x/y 折返しに変更、オプション
`lateral_wrap=true` 既定 off)。拡散は次元非依存なので変更なし。
`Simulation.mesh1d(z, nz)` 便宜メソッド。

**受入基準**:
- 1D モードの深さプロファイルが 3D (8×8 lateral) の x,y 平均と
  < 3% で一致 (Gaussian 注入 + 拡散)
- 同一物理で実行時間 1/50 以下
- MC lateral_wrap on で dose 損失 (out_of_domain) < 0.1%

## P3-h: デバイスシミュレータ連携

**目的**: デバイスシミュレータ (Sentaurus Device 等) に渡せる
構造+ドーピングの交換フォーマット出力。

**前提**: P1-11 (シリアライズ基盤)。

**設計方針**: 中立フォーマット 2 本立て: (1) 既存 VTU (点データ化した
濃度場を追加 — セル→ノード平均)、(2) JSON サイドカー
(`<name>.meta.json`: 領域→材料表、境界パッチ名、単位系、種リスト、
net doping の符号規約)。TDR 直接出力はプロプライエタリのため対象外。
`proc::export_device(path_prefix)` が `.vtu` + `.meta.json` を書く。

**受入基準**:
- 出力 VTU が ParaView で開ける (既存 writer 流用の回帰)
- meta.json が スキーマ (仕様書に JSON 例を全文掲載) に適合
- net doping (ND−NA) フィールドが正しい符号で出力される
