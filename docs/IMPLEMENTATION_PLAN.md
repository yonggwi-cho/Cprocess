# Cprocess 実装計画 — Sentaurus Process (SProcess) との差分分析

作成日: 2026-07-01
対象: `claude/quirky-bohr-7yfa3b` ブランチ時点の実装

本書は現状の Cprocess 実装を市販 TCAD プロセスシミュレータ
(Synopsys Sentaurus Process、以下 SProcess) と網羅的に比較し、
差分を埋めるための実装計画を優先度付きで示す。

---

## 1. 現状実装の要約

### 1.1 エンドツーエンドで動作する機能（デッキ + Python + proc:: 完備）

| 機能 | 実装内容 | 完成度 |
|------|---------|--------|
| メッシュ | 非構造四面体 (箱型 Kuhn 分割 / Gmsh v2・v4 読込)、領域タグ、境界パッチ | ★★★ |
| 解析的注入 | 縦方向 Gaussian、矩形窓の erf 横方向広がり、エネルギー→Rp/ΔRp テーブル | ★★ |
| MC 注入 (BCA) | ZBL 厳密散乱積分 (corteo 式テーブル)、Lindhard-Scharff 電子的阻止能、Lindhard-Robinson 結晶チャネリング (<100>/<110>/<111>)、Kinchin-Pease 損傷蓄積 + アモルファス化フィードバック、多材料輸送 (Si/レジスト/SiO₂/真空、Bragg 則)、tilt/rotation、OpenMP 並列 | ★★★★ |
| フォトリソ | 物理レジスト stack (photo/mask/mask_polygon/strip)、MC がレジストを実輸送 | ★★★ |
| 拡散 | FVM (二点フラックス + 非直交補正)、Fair 空孔モデル (D⁰/D⁻/D⁼/D⁺)、電場増速、多種連成 (電荷中性)、後退オイラー + Picard | ★★★ |
| TED | "+1" モデルで I 場をシード、I の拡散+再結合+表面シンク、ペア拡散増速 (1−fi)+fi·S、S 上限で {311} 緩衝近似 | ★★ |
| デポ/エッチ | セル再タグ方式 (ポリゴン footprint 指定可)。トポグラフィ物理なし | ★ |
| 線形ソルバー | CG/BiCGSTAB/GMRES、Jacobi + ILU(0) (レベルスケジューリング並列三角ソルブ)、SpMV/内積/AXPY OpenMP 化 | ★★★ |
| 行列組立 | 面彩色による競合フリー並列組立 | ★★★ |
| 出力 | VTK .vtu ASCII (ParaView) | ★★ |

### 1.2 スタンドアロン実装のみ（プロセスフロー未統合）

| モジュール | 実装内容 | 未統合の理由 |
|-----------|---------|-------------|
| 酸化 (`oxidation.cpp`) | Deal-Grove 1965 の**厚さ計算式のみ** (dry/wet, <100>)。メッシュを動かさず SiO₂ 領域も作らない | `oxidize` コマンド/proc:: 関数が存在しない |
| レベルセット (`levelset.cpp`) | φ 初期化 (Dijkstra 近似 SDF)、一次風上 HJ 移流、Sussman 再初期化、領域再タグ | エッチ/デポ/酸化のどれにも接続されていない |
| 応力 (`mechanics.cpp`) | Maxwell 粘弾性のセル毎更新式のみ。**FEM 平衡解なし**（変位場・ひずみ計算なし） | 呼び出し元がひずみ増分を渡す前提の素材のみ |
| ALE (`ale_mover.cpp`) | 境界/界面ノードの法線移動 (スカラー速度)、反転ガード、Laplacian 平滑化 | 酸化と手動デモ (`nmos_locos_flow.cpp`) でのみ結線 |
| リメッシュ (`remesh.cpp`) | tet 品質メトリック、エッジ分割、平滑化。**適応細分化・エッジ縮約・フリップなし** | 自動リメッシュのトリガが存在しない |

## 2. SProcess との網羅的差分

凡例: ✅=同等 / △=部分的 / ❌=未実装

### 2.1 イオン注入

| 機能 | SProcess | Cprocess | 差分 |
|------|----------|----------|------|
| MC BCA (Crystal-TRIM 相当) | ✅ | ✅ ZBL+チャネリング+損傷 | ほぼ同等の骨格 |
| 解析 Pearson-IV / dual-Pearson | ✅ | ❌ Gaussian のみ | **P1-1** |
| 解析テーブル (Taurus/advanced calibration) | ✅ 大規模較正 DB | △ 教科書 8 点テーブル | **P1-1** |
| 解析注入の tilt/rotation | ✅ | ❌ | P1-1 |
| 非平面表面からの共形深さ | ✅ | ❌ (平面 z_top 前提) | P2 |
| 真の化合物 BCA (SiO₂ を Si+O で) | ✅ | △ Bragg 則単一有効元素 | P3 |
| Cumulative damage → 次工程への引継ぎ | ✅ | △ MC 内のみ、+1 は別系統 | **P1-2** |

| 機能 | SProcess | Cprocess | 差分 |

| 活性化モデル (固溶度クランプ/クラスタ解離) | ✅ | △ 保存時クランプのみ | **P1-3** |

## 3. 実装計画

### フェーズ P1 — プロセスフロー完結性 (最優先)
「標準 CMOS フローがデッキ/Python だけで通る」ことを目標とする。
現状は酸化が完全に欠落しており、ここが最大の穴。

| ID | 項目 | 内容 | 規模 | 依存 |
|----|------|------|------|------|
| **P1-6** | 酸化のフロー統合 | `proc::oxidize(time, temp, wet)`: Deal-Grove+Massoud 薄膜補正 → 界面ノードを ALE で押上げ (2.2× 体積比で Si 消費/SiO₂ 生成) → SiO₂ 領域タグ → フィールド質量保存転写。1D 縦方向成長から開始 (平面 + マスク開口)。既存 oxidation/ale_mover を結線 | 中 | なし |
| **P1-4** | 界面偏析 + dose loss | Si/SiO₂ 界面の 3 相偏析 (偏析係数 m(T), 界面輸送係数 h)。拡散ソルバーの界面フラックス項に追加。B の SiO₂ への吸出しを再現 | 中 | P1-6 |
| **P1-3** | 活性化モデル | 拡散中の固溶度クランプ (現在は保存時のみ)。活性/不活性の分離 (不活性分は不動)。simple clustering: C_active = min(C, C_ss(T)) から開始 | 小 | なし |
| **P1-5** | RTA 温度ランプ | `diffuse` に ramp_rate / 温度テーブル対応。DiffuseOpts に時間依存 T(t)。ステップごとに D(T) 再評価 (既存 Picard 構造で対応可) | 小 | なし |
| **P1-2** | MC 損傷 → TED 接続 | MC の Kinchin-Pease 損傷配列を "+1" の代わりに I 場シードへ変換 (現在 +1 はドーパント形状コピー)。net displacement → I 過剰の物理的整合 | 小 | なし |
| **P1-1** | Pearson-IV 解析注入 | 4 モーメント (Rp, ΔRp, γ, β) Pearson-IV + チャネリングテールの dual-Pearson。tilt 対応。モーメントテーブル拡充 (B/P/As/Sb × 10keV-200keV) | 中 | なし |
| **P1-7** | エッチ/デポのメッシュ変形対応 | 現状のセル再タグを「表面適合」に改善: デポは extend_mesh_exact の多層版 (材料スタック)、エッチは表面セル削除+界面再構築。1D 縦方向のみでよい | 中 | P1-8 |
| **P1-8** | 適応リメッシュ (最小限) | 勾配ベースのエッジ分割 (濃度勾配が閾値超のエッジを split)、移動界面近傍の細分化。edge_split の face 再構築を自動化。full remesh は P2 | 中 | なし |
| **P1-9** | 多材料拡散 | SiO₂/poly 中の拡散係数テーブル追加、非 Si 領域を凍結解除しマスク→材料別 D に変更。界面条件は P1-4 と統合 | 中 | P1-4 |
| **P1-10** | パラメータ上書き機構 | 物性値 (D0, E_a, 偏析係数, C_I* 等) を struct にまとめ、Python から `sim.set_param("B.d0", ...)` で上書き可能に。較正作業の前提 | 小 | なし |
| **P1-11** | 状態保存/再開 + 1D 抽出 | フィールド+メッシュ+領域の独自バイナリ (or VTU 読込) で save/load。`sim.profile1d(species, x, y)` で深さプロファイル抽出 | 小 | なし |

**P1 完了時に可能になるフロー例:**
ゲート酸化 → poly デポ → ゲートエッチ → LDD 注入 (Pearson) → スペーサ →
S/D 注入 (MC+損傷) → RTA スパイクアニール (TED+活性化+偏析) → 保存

### フェーズ P2 — 物理精度の深化

| ID | 項目 | 内容 | 規模 |
|----|------|------|------|
| P2-1 | フル点欠陥モデル | I と V の 2 方程式輸送 + I-V 再結合 + {311} クラスタの明示的生成/解離 (Ostwald ripening 律速)。現行 run_ted を置換。5-stream (dopant-I/dopant-V ペア輸送) はその後 | 大 |

| P2-4 | 2D/3D 酸化 | 酸化剤の拡散-反応方程式 (SiO₂ 中 C(η) FVM) + 界面反応 → 局所成長速度場 → ALE 法線速度場 (現状スカラーを場に拡張) + 粘性流/応力減速。bird's beak 再現 | 大 |

| P2-7 | GDS レイアウト入力 | GDSII/OASIS ポリゴン読込 → mask_polygon へ | 小 |
| P2-8 | ドーパント追加 | In, C (C-I クラスタで TED 抑制), F, Ge。Ge は SiGe 物性の入口 | 中 |

### フェーズ P3 — 商用同等機能 (長期)

- 真の化合物 BCA (二元衝突を成分元素ごとに)
- エピタキシー成長・固相エピ (SPER)・シリサイド化
- 応力依存の拡散/酸化/活性化、SiGe 歪みエンジニアリング
- 1D/2D 高速モード、デバイスシミュレータ連携フォーマット
- 較正 DB の体系化

## 4. メッシャー実装計画 (M シリーズ)

物理計画 (P1-6 酸化、P1-8 適応リメッシュ、P2-4 2D/3D 酸化) の基盤。
現状: `edge_split` (face 再構築が手動)、品質メトリック、Laplacian 平滑化のみ。
エッジ縮約・フリップ・適応細分化・自動トリガは未実装。

| ID | 項目 | 内容 | 規模 | 動機/依存 |
|----|------|------|------|-----------|
| M-1 | エッジ分割の完全自動化 | `edge_split` 後の face/topology 再構築を内部化し、複数エッジの一括分割 API に。分割後の `Mesh::finalize()` 自動呼出 | 小 | P1-8 の前提 |
| M-2 | 適応細分化ループ | 誤差指標 (濃度勾配・界面距離) → エッジ選択 → 分割 → 場の転写 (既存 field_transfer) → 品質回復、の自動ループ。`proc::refine(criteria)` として公開 | 中 | 急峻な TED プロファイル・移動界面の解像 |
| M-3 | 粗視化 (エッジ縮約) | 勾配が緩んだ領域のセル統合。リンク条件 (link condition) 検査 + 反転ガード + 場の保存的転写 | 中 | アニール後のセル数増大の抑制 |
| M-4 | 界面適合リメッシュ | 酸化・エッチの移動界面をエッジ/面に整合させる局所再接続 (2-3 / 3-2 フリップ)。界面の階段状アーチファクト解消 | 中 | **P1-6 酸化、P2-4 の事実上の前提** |
| M-5 | 品質駆動リメッシュ | ALE 移動後の sliver 検出 → フリップ/平滑化/分割による自動修復パス。`ale_move` の後処理として結線 | 中 | 酸化の大変形対応。P1-6 と同時期に必要 |
| M-6 | 異方性メッシュ (長期) | 界面法線方向に細かく接線方向に粗いメトリックテンソルベースの細分化 | 大 | セル数を約 1 桁削減 |

## 5. ソルバー実装計画 (S シリーズ)

現状: CG/BiCGSTAB/GMRES + Jacobi/ILU(0)。ILU(0) は三角ソルブのみ並列
(レベルスケジューリング)、**分解フェーズは逐次**。時間刻みは等間隔。

| ID | 項目 | 内容 | 規模 | 動機/依存 |
|----|------|------|------|-----------|
| S-1 | ILU(0) 分解の並列化 | レベルスケジューリングを分解フェーズにも適用、または反復型 ILU (Chow-Patel 2015)。現在の Amdahl 律速 (拡散 1.95×/4 コア) の主因を解消 | 中 | 費用対効果最大。先行実施推奨 |
| S-2 | ブロック連立ソルバー | dopant + I + V 連成 (5-stream) 用のブロック CSR 構造とブロック Jacobi/ILU 前処理。種間結合を行列内に取り込む | 大 | **P2-1 フル点欠陥の前提** |
| S-3 | Newton-Krylov オプション | 硬い反応項 (クラスタ動力学) 向けに Picard → JFNK (Jacobian-free Newton-Krylov) 切替。線形化は有限差分方向微分 | 中 | P2-1/P2-2 の収束性確保 |
| S-4 | AMG 前処理 (中期) | セル数 10⁶ 超で ILU の反復数増大に対応。単純な smoothed aggregation AMG から開始 | 大 | 大規模 3D。PA-2 の後 |
| S-5 | 適応時間刻み | 局所打切り誤差推定 (二次外挿 or 埋込みペア) による dt 自動制御。現在は time/50 の等間隔 | 小 | RTA スパイク・TED 初期の急峻さ。P1-5 と相乗 |

## 6. 並列化実装計画 (PA シリーズ)

実施済み: MC (チャンク並列・決定的シード)、SpMV/内積/AXPY、面彩色による
競合フリー組立、ILU(0) 三角ソルブ。実測: 拡散 1.95×/4 コア (166k セル)。
残存ボトルネック: ILU 分解の逐次性、SpMV のメモリ帯域。

| ID | 項目 | 内容 | 規模 | 動機/依存 |
|----|------|------|------|-----------|
| PA-1 | 残存逐次部の並列化 | S-1 (ILU 分解) と M-2 (リメッシュ) の並列版。彩色ベースの並列エッジ分割・並列フリップ | 中 | S-1/M-2 と一体で実施 |

## 7. 実装順序の提案

依存関係と効果から、次のスプリント構成を提案する
(M/S/PA を物理スプリントに織り込む):

```
Sprint 0 (基盤先行):          S-1 ILU並列分解 → M-1 エッジ分割自動化
                              → M-5 品質駆動リメッシュ → M-4 界面適合
Sprint 1 (フロー最大の穴):    P1-6 酸化統合 → P1-4 偏析 → P1-9 多材料拡散
Sprint 2 (アニール精度):      P1-3 活性化 → P1-5 RTA ランプ (+S-5 適応dt)
                              → P1-2 MC損傷→TED
Sprint 3 (注入精度+基盤):     P1-1 Pearson-IV → P1-10 パラメータ機構
                              → P1-8 適応リメッシュ (M-2) → P1-7 エッチ/デポ改善
                              → P1-11 保存/再開
Sprint 4+ (深化):             P2-1 (S-2/S-3 と一体) → P2-4 (M-6)
                              → PA-2 → S-4 → PA-4/PA-5
```

Sprint 0 を酸化統合の前に置く理由: 酸化で界面が動き出すと、メッシュ品質の
自動回復 (M-5) と界面適合 (M-4) がないと大変形時に破綻するため。
ソルバーは当面現行で足りるが、S-1 のみ費用対効果が高く先行させる。
